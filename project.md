# Требования к итоговому проекту

Формат: исследовательско-прикладной проект

## 1. Общие требования

- Проект выполняется в группе 1–3 человека.
- Тема проекта выбирается магистрантами самостоятельно и должна быть связана с реальной задачей анализа данных или прогнозирования.
- Желательно, чтобы тема проекта была связана с темой будущей магистерской диссертации или областью научных интересов магистранта.
- Можно использовать открытые датасеты и самостоятельно собранные данные.

## 2. Обязательные этапы проекта

### 2.1 Постановка задачи
В проекте должны быть сформулированы:
- предметная область
- гипотеза исследования
- формальная постановка задачи машинного обучения (классификация, регрессия, кластеризация и пр.), решаемая оптимизационная задача (если применимо).
- критерий качества модели

### 2.2 Разведочный анализ данных (EDA)
Обязательно выполнение разведочного анализа данных (EDA), включая:
- описание источника данных
- анализ пропусков
- анализ распределений признаков
- анализ зависимостей между признаками
- визуализацию данных

По результатам разведочного анализа данных необходимо сделать осмысленные выводы, влияющие на дальнейшее моделирование.

### 2.3 Подготовка данных

В проекте должна быть реализована подготовка данных:
- обработка пропусков
- кодирование категориальных признаков
- масштабирование признаков (при необходимости)
- генерация новых признаков (feature engineering)

Желательно оформить pipeline обработки данных.

### 2.4 Построение моделей

Необходимо обучить несколько моделей, включая:

- базовую (baseline) модель
- не менее двух алгоритмов машинного обучения, изученных в курсе

### 2.5 Подбор гиперпараметров

- Для всех моделей должен быть выполнен подбор гиперпараметров.
- Необходимо сравнить результаты до и после оптимизации.

### 2.6 Оценка качества модели

- Обосновать выбор метрик качества.
- Провести сравнение моделей по выбранной метрике/метрикам.
- Визуализировать результаты (хотя бы в виде таблицы).
- Объяснить, почему выбранная модель лучше.

### 2.7 Интерпретация результатов

- Проанализировать важность признаков и/или распределение остатков/ошибок модели.
- Обсудить ограничения модели.
- Результат — отклонение или неотклонение исследовательской гипотезы.

### 3. Итоговые материалы

- Проект должен быть выполнен в Jupyter Notebook. Результаты должны быть воспроизводимы.
- Каждая команда должна предоставить репозиторий проекта на github или прислать jupyter notebook файл.
- Notebook должен содержать код, все рассуждения и при необходимости инструкцию к воспроизведению результатов.
- Презентация (~10 минут).

## Оценивание:

| Критерий                            | Баллы |
| - | - |
| EDA и подготовка данных             | 15    |
| Построение baseline модели          | 5     |
| Построение альтернативных моделей   | 10    |
| Подбор гиперпараметров              | 10    |
| Анализ результатов                  | 10    |
| Защита проектов                     | 50    |
